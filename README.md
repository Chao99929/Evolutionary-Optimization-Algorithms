# Evolutionary Optimization Algorithms

A collection of C++ implementations of classical and adaptive evolutionary
optimization algorithms for continuous numerical optimization.

This repository includes implementations of Differential Evolution (DE),
JADE, SHADE, L-SHADE, and Particle Swarm Optimization (PSO).

## Implemented Algorithms

| Algorithm | Description |
|-----------|-------------|
| **DE** | Classical Differential Evolution using mutation, crossover, and selection |
| **JADE** | Adaptive DE with current-to-pbest mutation and parameter adaptation |
| **SHADE** | Success-history based adaptive Differential Evolution |
| **L-SHADE** | SHADE with Linear Population Size Reduction (LPSR) |
| **PSO** | Particle Swarm Optimization based on individual and social learning |
